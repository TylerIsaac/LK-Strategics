# LK Strategics – Fashion Brand Strategy Website

A modern, responsive one-page website for **LK Strategics**, a boutique consultancy specializing in fashion communication, brand development, and strategic launches. This site was designed to showcase services, highlight successful brand collaborations, and provide a downloadable PR guide.

## 📁 Folder Structure

```
/lizaPortfolio/
├── /assets/             # Images, icons, and the downloadable PDF
├── /docs/               # Site source files (for GitHub Pages deployment)
│   ├── index.html       # Main HTML file
│   └── style.css        # Custom styles
└── README.md
```

> ⚠️ Note: The `/docs/` folder is used for GitHub Pages deployment.

## ✨ Features

- 🔥 Smooth animations using [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- 📱 Mobile-first responsive layout (Bootstrap 5)
- 🎬 Embedded and styled YouTube case study
- 🖼️ Scroll-triggered animated image collages
- 📄 Downloadable PR Methods Guide PDF
- 🔗 External links open in new tabs with accessibility support
- 🌐 Custom domain via GoDaddy

## 📦 Tech Stack

- HTML5
- CSS3 + Bootstrap 5
- JavaScript (vanilla)
- AOS animation library
- Font Awesome icons
- GitHub Pages

## 🚀 Deployment

This site is hosted using **GitHub Pages**.

### Steps:

1. Move your source files to the `/docs/` folder.
2. Go to **GitHub → Settings → Pages**.
3. Select:
   - **Source**: `main` branch
   - **Folder**: `/docs`
4. Set a **custom domain** if using one (e.g. via GoDaddy).
5. Make sure downloadable files (like PDFs) do not have spaces in filenames.
